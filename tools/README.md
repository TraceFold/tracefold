# tools/

One script, and it exists to stop a particular kind of lie.

---

| File | What it does |
| :--- | :--- |
| [`e2e.sh`](e2e.sh) | Clones this repository from git into a scratch directory and builds and tests **only what the clone contains** — never the working tree it was started from. A green working tree can therefore never be mistaken for a green repository. The script's own header states its assumptions. |

---

## Why it clones instead of building in place

A working tree holds files that are not committed: a fixture someone generated by hand, a
dependency added and not saved, a test that passes because of something lying around. Building in
place measures that tree. Building a fresh clone measures what a stranger would actually get, which
is the only number worth printing.

This is the same discipline the product applies to receipts — a claim is worth what an independent
party can re-check, not what the party making it can see on their own machine.

## Running it

```bash
bash tools/e2e.sh
```

Expect it to take as long as a cold build of the workspace: it starts from nothing on purpose.
Toolchain version comes from [`rust-toolchain.toml`](../rust-toolchain.toml), which is the single
place the pin is declared. [`.devcontainer/`](../.devcontainer) gives you a prebuilt environment if
you would rather not wait through the first build locally.
